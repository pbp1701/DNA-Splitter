# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-05-05

### Added
- Initial project setup with version tracking and dependency pinning
- README with DNA capture pattern documentation
- `pyproject.toml` for reproducible builds
- `requirements.txt` for quick studio machine setup
- `.gitignore` for audio files and personal library data
- Project infrastructure files

### Notes
- Foundation ready for core feature development
- Audio analysis library (librosa) locked to v0.10.1
- Python 3.8+ support
